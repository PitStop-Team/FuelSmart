# 가는길 주유 (RouteFuel)

표시 가격이 아니라 "이 차로, 이 경로에서" 실제로 드는 총비용(기름값 + 이동 비용 - 할인)이 가장 낮은 주유소를 계산해, 내장 내비로 바로 안내하는 Pleos Connect 차량용 앱.

- 총비용 기준 추천: 가격표가 아니라 예상 총비용이 가장 낮은 주유소를 고른다.
- 내비 경로 기반 거리: 직선거리 추정이 아니라 실제 경로 거리를 쓰는 것을 목표로 한다.
- 주행 중에는 카드 1장과 음성, 정차 중에는 상세 화면을 보여주는 것을 목표로 한다.

차량 SDK 연동과 음성, 주행/정차 화면은 아직 구현 전이다. 현재 상태는 [구현 현황](#구현-현황)에 적었다.

## 해결하는 문제

- 가격표만 보고 먼 주유소로 가면 이동 비용 때문에 오히려 손해일 수 있다.
- 할인 조건(리터당 할인, 1회 한도)이 복잡해서 실제 가격을 비교하기 어렵다.
- 운전 중에 폰으로 주유소를 찾고 비교하는 것은 위험하다.

## 계산 방식

```
할인액      = min(리터당 할인 × 주유량, 1회 할인 한도)
기름값      = 표시 가격 × 주유량 - 할인액
이동 비용   = 이동 거리 ÷ 연비 × 표시 가격
예상 총비용 = 기름값 + 이동 비용
예상 이득   = 기준 주유소 예상 총비용 - 해당 주유소 예상 총비용
```

기준 주유소는 후보 중 가장 가까운 곳이다(거리가 같으면 싼 곳). 1회 한도를 입력하지 않으면 한도 없이 계산한다.

계산 예 (연비 12km/L, 주유량 40L, 할인 없음, 이동 거리는 편도 경로 거리):

| 주유소 | 표시 가격 | 이동 거리 | 기름값 | 이동 비용 | 예상 총비용 |
|---|---|---|---|---|---|
| 기준 (가까운 곳) | 1,700원 | 0.7km | 68,000원 | 99원 | 68,099원 |
| 먼 곳 | 1,640원 | 4.2km | 65,600원 | 574원 | 66,174원 |

먼 곳의 예상 이득은 68,099 - 66,174 = 약 1,925원이다.

## 거리 계산

이동 거리는 `RouteDistanceProvider`(내비 경로 기반 실제 도로 거리)에서 받은 값을 우선 쓴다. 값을 받지 못하면 직선거리에 구간별 계수를 곱해 보정한다.

| 직선거리 | 계수 |
|---|---|
| 0~1km 미만 | 1.85 |
| 1~3km 미만 | 1.52 |
| 3~5km 미만 | 1.36 |
| 5km 이상 | 1.4 |

현재 앱의 `RouteDistanceProvider`는 사용자 입력 구현(등록한 값이 없으면 empty)이라, 항상 구간별 계수로 보정한다.

계수의 근거는 [docs/road-distance-check.csv](docs/road-distance-check.csv)다. 강남역 반경 5km 주유소 19곳의 도로 거리를 실측했고, 전체 합계 비율은 1.455, 중앙값은 1.419이다. 한 지점 기준이라 추가 보정이 필요하다.

## 주요 기능

아래는 앱이 갖추려는 기능이다. 실제 구현 여부는 [구현 현황](#구현-현황)을 본다.

| 기능 | 설명 |
|---|---|
| 예상 총비용 1위 카드 | 예상 이득이 가장 큰 주유소를 카드 한 장으로 보여준다. |
| 가는 길에 들르기 | 경로 위 주유소를 경유지로 제안한다. 운전자가 승인한 뒤에만 경로를 바꾼다. |
| 연료 부족 자동 제안 | 연료 잔량이 기준 아래로 내려가면 앱이 먼저 근처 이득 1위 주유소를 제안한다. |
| 내 차, 내 카드 반영 | 연비, 브랜드별 할인(리터당, 1회 한도), 선호/숨김 브랜드를 계산에 반영한다. |
| 음성 호출과 승인 | "근처에서 제일 싼 곳 알려줘"로 부르고, "응/아니"로 승인한다. |
| 주행/정차 화면 분리 | 주행 중에는 카드 1장과 음성, 정차 중에는 목록과 계산 내역을 보여준다. |
| 계산 기준 표시 | 연비와 주유량이 기본값인지, 거리가 추정값인지 밝힌다. |

## 차량 특화

| 항목 | 폰 앱 | 차량용 |
|---|---|---|
| 연비 | 직접 입력 | 차량 데이터, 미지원 시 입력값 |
| 이동 거리 | 직선거리 추정 | 내비 경로 기반 |
| 길안내 | 외부 앱 호출 | 내장 내비에 목적지와 경유지 설정 |
| 조작 | 터치 | 주행 중 음성, 카드 1장 |
| 맥락 | 현재 위치 | 목적지, 경로, 주행 상태 |

## 구현 현황

| 항목 | 상태 |
|---|---|
| 계산 엔진 (`:domain`) | 구현됨 |
| 구간별 거리 보정 | 구현됨 (예상 이득 계산과 목록, 즐겨찾기에 연결) |
| 차량 연비/연료 잔량 (`VehicleDataSource`, Vehicle SDK) | 구현됨 (연비는 계산에 반영, 잔량은 읽기만 함. 미지원이면 입력값 사용) |
| 내비 제어 (`NavigationController`, NaviHelper SDK) | 구현됨 (목적지, 경유지 추가/삭제, 위치와 경로 정보 조회) |
| 경로 거리 인터페이스 (`RouteDistanceProvider`) | 차량 SDK 연동 전(인터페이스와 모의 구현 있음) |
| 주유소 목록과 1위 카드 화면 | 구현됨 |
| 브랜드별 할인과 선호/숨김, 내 차 정보 입력 | 구현됨 |
| 즐겨찾기, 집/회사 위치 비교 | 구현됨 |
| 연료 부족 자동 제안 | 구현됨 (잔량 25% 미만이면 주변 이득 1위 1곳을 한 번 제안하고, 35% 이상 회복하면 다시 제안. 경유 모드 비교는 없고 주변 목록에서만 고름) |
| 경유지 추가 승인 화면 | 구현됨 (큰 버튼 승인 화면, 승인하지 않으면 내비게이션에 요청하지 않음) |
| 주행/정차 화면 전환 | 구현됨 (정차 판단은 브레이크 페달을 3초 이상 밟고 있는지로 추정) |
| 음성 호출과 승인 | 미구현 (TextToSpeech, SpeechToText SDK가 제공 준비 중) |

## 프로젝트 구조

```
:domain   순수 Java 모듈 (Android 의존 없음)
  model/       주유소, 내 차 정보, 할인 규칙, 예상 이득 결과 등
  util/        예상 이득 계산, 목록 구성, 좌표 변환, 금액 표시
  navigation/  내비 제어, 경로 거리 인터페이스와 구현, 구간별 거리 보정
  vehicle/     차량 데이터 인터페이스와 구현
:app      Android 앱
  data/        Room, 설정 저장, 오피넷/카카오 로컬 API, 모의 데이터
  viewmodel/   화면 상태와 조회 흐름
  ui/          목록 화면, 상세, 브랜드 설정, 내 차 정보 입력
```

## 실행 방법

필요한 환경:

- JDK 17 (Gradle 8.6, Android Gradle Plugin 8.4.0)
- Android SDK: compileSdk 34, targetSdk 34, minSdk 28
- 프로젝트 경로에 한글이 있으면 테스트가 실패할 수 있으므로 영문 경로를 권장한다.

프로젝트 루트의 `local.properties`(커밋하지 않는 파일)에 다음 항목을 둔다.

| 항목 | 설명 |
|---|---|
| `sdk.dir` | Android SDK 경로 |
| `USE_MOCK_DATA` | 기본값 `true`. `false`로 적은 경우에만 실제 오피넷 API를 쓴다. `true`면 앱에 들어 있는 모의 데이터(강남역 주변)를 쓴다. |
| `OPINET_API_KEY` | 실제 오피넷 API용. 없으면 `USE_MOCK_DATA=false`일 때 가격을 가져오지 못하고 키 없음 안내를 보여준다. |
| `KAKAO_REST_API_KEY` | 장소 검색용. 없으면 장소 검색을 쓸 수 없다. |

```
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # 디버그 빌드
```

## APK

저장소에 APK는 포함하지 않는다. `./gradlew assembleRelease`로 빌드하면 `app/build/outputs/apk/release/`에 생긴다.
